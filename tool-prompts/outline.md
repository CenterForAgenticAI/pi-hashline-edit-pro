Return a structural outline of one file: a `=== path (language) — N lines ===` header, then one `anchor│content` row per symbol, where the content is the first line of that symbol's declaration (annotations and attributes excluded). A `[limit N]` line under a multi-line symbol is the span to pass as `read`'s `limit` when reading that symbol's body from its anchor. A `[N nested]` line marks children hidden by `depth`. Files the parser cannot outline fall back to a head-and-tail preview. A row is editable with replace and insert when its line is shown whole; a row whose line is too long is clipped with a trailing `...` and is not served for editing, so read that line first.

The outline is a map, not the file: it shows each symbol's declaration line only, so read the span before editing inside a body. Rows cover top-level declarations and the members of a type or module; a declaration inside a function body is never a row, whatever `depth` you pass. Anchors are lowercase letters and stay valid until their line is edited.
