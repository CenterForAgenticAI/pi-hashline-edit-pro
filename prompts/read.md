Read a text file and return it as `anchor│content` rows, one per line: a 4-character anchor (letters only, case-sensitive), the `│` separator, then the line content. Target lines in edits by anchor, never by content or line number. Page long files with `offset` and `limit`; when the output says truncated, continue with the hinted `offset/limit`. Images attach visually; binary, directory, and UTF-16/UTF-32 text are rejected; an empty file returns one empty row you can replace to seed content.

Address a re-read by anchor instead of line number: `anchor` centers the window on a served line (`before`/`after` set the span, defaults 0 and 20), and `from`+`to` read an inclusive anchored range. Anchor addressing cannot be combined with `offset`/`limit`; a stale anchor is refused with the current context rows and fresh anchors. Pass `outline: true` for an anchor-stamped structural outline of a large file instead of its lines: supported languages (tree-sitter grammars plus Markdown headings) return nested symbols with line ranges, other files return a head/tail preview, and outline anchors address the real lines, so they can be read or edited immediately.
